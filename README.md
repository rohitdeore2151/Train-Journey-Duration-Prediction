# 🚆 Train Journey Duration Prediction

A Data Science project focused on predicting train journey duration using **Linear Regression**.

## 📌 Project Overview

This project demonstrates a complete data science workflow, including data preprocessing, exploratory data analysis, model implementation, evaluation, and predictions.

## 📂 Project Contents

- Source code and model implementation
- Original and cleaned datasets
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Linear Regression model
- Model evaluation and predictions

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 🎯 Objective

The objective of this project is to use data-driven techniques and a **Linear Regression model** to predict train journey duration.

## 📊 Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Model Building using Linear Regression
5. Model Evaluation
6. Predictions
