DATA SCIENCE INTERNSHIP PROJECT

Name: Rohit Shravan Deore
Domain: Data Science

Project Title:
Train Journey Duration Prediction

PROJECT DESCRIPTION:
This project analyzes train journey data and develops a Machine Learning
prediction system to predict journey duration.

TASKS COMPLETED:

Level 1:
Data Understanding and Data Quality Analysis

Level 2:
Train Route, Distance, Stops and Journey Duration Analysis

Level 3:
Exploratory Data Analysis (EDA), Station Analysis and Correlation Analysis

Level 4:
Data Visualization and Insights

Level 5:
Linear Regression Model Development and Evaluation

Level 6:
Final Journey Duration Prediction System and Actual vs Predicted Visualization

MODEL USED:
Linear Regression

FEATURES USED:
1. Total_Distance
2. Number_of_Stops

TARGET VARIABLE:
Journey_Duration_Min

MODEL EVALUATION:
Mean Absolute Error (MAE): 152.21
Root Mean Squared Error (RMSE): 237.39

FINAL RESULT:
A Linear Regression model was developed to predict train journey duration
using total distance and number of stops, along with visualization of
Actual vs Predicted Journey Duration.
